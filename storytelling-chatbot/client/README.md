# Storytelling Chatbot – web client

A Next.js client for the storytelling bot, built with the
[Pipecat React SDK](https://docs.pipecat.ai/client/react/introduction) and the
SmallWebRTC transport.

See the [top-level README](../README.md) for setup instructions. In short:

```bash
npm install
cp env.example .env.local   # point BOT_START_URL at your server
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).
